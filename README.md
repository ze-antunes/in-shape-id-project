# InShape — Interaction Design Project

**InShape** is a Unity-based project associated with interaction design.

## Repository structure

- `InShape/` — Unity project directory
- `InShape/Assets/` — Unity assets and scenes
- `InShape/Packages/` — Unity package definitions
- `InShape/ProjectSettings/` — Unity project configuration
- `Experience.unitypackage` — exported Unity asset package

## Opening the Unity project

1. Install Unity Hub.
2. Choose **Add project from disk** and select the `InShape/` folder.
3. Use the Unity version specified by `InShape/ProjectSettings/ProjectVersion.txt`, where available.
4. Open the project and inspect the scenes under `Assets/`.

Alternatively, the `Experience.unitypackage` file can be imported into a compatible Unity project.

## Notes

This repository contains generated Unity directories such as `Library/` and `Logs/`. These are usually excluded from version control in new Unity projects.

The interaction flow, dependencies and supported platforms should be verified in the Unity project before distributing builds.
